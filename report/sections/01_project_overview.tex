\section{Project Overview}
\label{sec:project_overview}


% ============================================================
% Objective
% ============================================================

\subsection{Objective}

The purpose of this project is to characterize a selected set of
SKY130A MOS devices and generate practical device data for subsequent
analog IC design.

The objective is not to reproduce MOS transistor theory or to
exhaustively characterize every device available in the PDK.
Instead, the characterization focuses on quantities that are directly
useful when selecting a device, estimating its operating point, and
performing transistor sizing.

The characterized device families are:

\begin{itemize}
	\item the standard \qty{1.8}{\volt} NMOS and PMOS devices;
	\item the \code{nfet\_03v3\_nvt} native NMOS;
	\item the \code{nfet\_05v0\_nvt} native NMOS.
\end{itemize}

Additional device families can be characterized later when required by
a specific circuit architecture.


% ============================================================
% Characterization scope
% ============================================================

\subsection{Characterization Scope}

The characterization concentrates on the quantities most useful during
analog design:

\begin{itemize}
	\item drain-current transfer characteristics;
	\item output-characteristic families;
	\item threshold voltage $V_{TH}$;
	\item saturation voltage $V_{DSAT}$;
	\item transconductance efficiency $g_m/I_D$;
	\item effective MOS gate capacitance.
\end{itemize}

The main purpose of the generated curves is to provide reusable sizing
and biasing references rather than to illustrate fundamental MOS
operation.


% ============================================================
% Design flow
% ============================================================

\subsection{Characterization Flow}

The characterization flow uses Xschem testbenches and the SKY130A
device models simulated with ngspice inside the IIC-OSIC-TOOLS
environment.

DC and AC sweeps are exported as numerical data and post-processed with
Python to generate the figures presented in this report.

Unless otherwise stated, the results correspond to the nominal TT
process corner at \qty{27}{\degreeCelsius}.

\begin{designnote}
	The voltage limits reported in
	Table~\ref{tab:device_quick_reference} correspond to the documented
	SPICE-model operating ranges and should not be interpreted as device
	absolute-maximum ratings. The documented ranges are taken from the
	SKY130A device documentation~\cite{sky130_device_details}.
	
	The extracted quantities use the reference transfer-characterization
	biases: $|V_{GS}|=\qty{1.8}{\volt}$ and
	$|V_{DS}|=\qty{0.9}{\volt}$ for the standard \qty{1.8}{\volt} devices,
	$V_{GS}=\qty{3.3}{\volt}$ and $V_{DS}=\qty{1.65}{\volt}$ for the
	\code{nfet\_03v3\_nvt}, and $V_{GS}=\qty{5}{\volt}$ and
	$V_{DS}=\qty{2.5}{\volt}$ for the \code{nfet\_05v0\_nvt}.
\end{designnote}
