\subsection{Use in Future Designs}

The characterization database generated in this project is intended
to support subsequent SKY130A analog circuit designs.

Rather than beginning each new circuit with arbitrary transistor
dimensions, device operating points can be selected using the
characterized relationships between current density, transconductance
efficiency, intrinsic gain and geometry.
